# Authentication Backend API

Backend authentication system built with Node.js, Express.js, MongoDB, JWT, bcrypt and cookies.

## Features

- User Signup
- User Login
- User Logout
- Password Hashing with bcrypt
- JWT Authentication
- HTTP-only Cookies
- MongoDB with Mongoose

## API Endpoints

### Signup
POST `/api/signup`

### Login
POST `/api/login`

### Logout
POST `/api/logout`

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcrypt
- cookie-parser
